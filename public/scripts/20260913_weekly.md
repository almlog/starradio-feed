## 特集回「エンジニアと生成AIの付き合い方 —— 未来のエンジニアは、何をしているのか」

## Part 1: オープニング + プライベートトーク

**もえちゃん**: おはようございます、みなさんお久しぶりです！2日ぶりのスタラジ、増刊号のお時間ですよ〜。担当は東大博士課程のもえです！

**レイナ姐さん**: あたし、看護師のレイナよ。ちょっとお休みいただいてたけど、無事復活したわ。

**もえちゃん**: しかも今回、本当は昨日の土曜日にお届けする予定だったんですが、スタジオの機材トラブルで1日遅れの日曜配信になっちゃいました。すみません！

**レイナ姐さん**: 機材が言うこと聞かないの、あたしの夜勤明けの電子カルテと同じよ。まあ、こういう日もあるでしょ。

**もえちゃん**: なんかそのたとえ、妙にリアルなんですよ！さて、姐さん、この1週間、プライベートはどうでした？

**レイナ姐さん**: あたしね、この週末に見ようと決めてる映画があるのよ。{Penske Media（The Hollywood Reporter）|ハリウッド・リポーター}が報じてたけど、『プラクティカル・マジック2』が北米ボックスオフィスのトップを取って、しかも同時に『スパイダーマン』が国内歴代最高記録を狙ってるっていう。

**もえちゃん**: え、両方すごくないですか？

**レイナ姐さん**: そうなの。プラクティカル・マジック1作目は九十年代の魔女姉妹の話で、あたしが歌劇団時代に楽屋でみんなで回し見してた思い出の作品なのよ。続編がついに動くって、あたし夜勤明けにこれ観に行くわよ。

**もえちゃん**: いい〜、姐さんのその「夜勤明けにミュージカル映画」の生活、憧れます。

**レイナ姐さん**: 憧れないで、体はもう限界よ。あと{Penske Media（Rolling Stone）|ローリング・ストーン}が『ファミリー・ストーン』の続編がオリジナルキャストで動くって書いてて、これも観たいのよね。

**もえちゃん**: 続編ラッシュがすごい年ですよね〜。わたしは今週、アイドル時代の同期と月イチのカラオケがあって、そこで話題になったのが{ジャパンミュージックネットワーク（BARKS）|バークス}の記事、INIの木村柾哉くんが5周年を迎えて「リーダーとしての矜持」を語ったっていうインタビュー。

**レイナ姐さん**: 正直に言っていい？あんた、元アイドルの目線でそういう記事読むと、絶対しんどい部分に食いつくでしょ。

**もえちゃん**: バレました？わたし、リーダー経験してるから「みんなを引っ張る側の景色」って自分の記憶と重なっちゃって、記事の中で「グループを続けさせる責任」って言葉があってですね、そこでちょっと涙腺きました。

**レイナ姐さん**: あんた博士課程でも夜中に泣きながら論文書いてそうだけど。

**もえちゃん**: それは事実なんですよ！話が涙で終わりそうなので、次いきましょう！

## Part 2: 土曜（なった日曜）ニュースダイジェスト

**レイナ姐さん**: 土曜どころか日曜になっちゃったけど、注目のニュース、テンポよく行くわよ。

**もえちゃん**: まず{Bloomberg L.P.|ブルームバーグ}、「ラリー・エリソン、オラクル株の最大5000万株売却計画を撤回」というニュース。オラクル創業者が数千万株規模の売却を予告してたのを引っ込めたって話で、市場はこれを素直に「保有継続シグナル」と受け取ってます。

**レイナ姐さん**: 数千万株の売り予告を引っ込めるって、素人でも「機嫌のいい理由」があるとしか思えないでしょ。

**もえちゃん**: そうなんですよ、この1週間、オラクルはAIクラウドの受注絡みで相当ポジティブな話が続いてたので、その延長線で読めますね。

**レイナ姐さん**: 続いて{BBC|ビービーシー}、こっちは大御所の話よ。「アンソロピックのアモデイCEOがAI開発を減速させろと呼びかけ」。ブレーキ踏め、って本人が言ったの。

**もえちゃん**: これ、ヤバくないですか！？アンソロピック、まさに世界最速で走ってる会社ですよ。そのCEOが自分でスピード緩めろって言うのは、レース中に自分の車を降りるのに近い発言なんです。

**レイナ姐さん**: ただしね、これ「本当に降りる」んじゃなくて「みんな一緒に速度落とそう」って呼びかけよ。あたしはこの発言、規制当局向けメッセージも半分入ってると読んでる。

**もえちゃん**: 大人の読み方きた〜。最後に{アイティメディア}の記事、「ルールを作る管理職ほどシャドーAIを使っている」という「AI白書2026」の調査結果です。ガイドラインを作った本人が、一番隠れて使ってた、と。

**レイナ姐さん**: そりゃそうよ。ルール作る側が一番手を動かしたいの、業界問わずでしょ。あたしの現場でも「決めた本人が一番例外運用する」の、あるあるだから。

## Part 3: 特集・前編「今、エンジニアは実際に何をしているのか」

**もえちゃん**: ここから今日のメインです。テーマは「エンジニアと生成AIの付き合い方 —— 未来のエンジニアは、何をしているのか」。

**レイナ姐さん**: 前置きを1つだけ言わせて。この番組では「AIがコードの大半を書く未来が本当に来るか」は議論しない。来る。放っておいても来る。だからその前提で、「じゃあ人間は何をしてるのか」を、この1週間の記事から具体的に見ていくわよ。

**もえちゃん**: 潔い前置き、いいですね。じゃあまず、この言葉から。{Zenn|ゼン}の記事タイトル「これを仕事にできないかなぁ ——Claude Codeに1セッション相談したら、妄想ではなく検証可能な設計問題になっていた」。

**レイナ姐さん**: 妄想が、1セッションで、検証可能な問題になった。

**もえちゃん**: そう。この方、ふわっとしたアイデアをClaude Codeにぶつけたら、要件が分解されて、確認すべきコンポーネントが並んで、「次はここを検証してください」まで返ってきた。人間側は考えるより先に「相棒に一回投げる」動きに変わってるんですよ。

**レイナ姐さん**: あたしね、看護の現場で似た変化を見てるのよ。昔は先輩に相談する前に「自分の中で整えてから」持ってったの。今は電子カルテのアシスタントが下書きを埋めてきて、あたしたちは「間違ってないか」を見る側になってる。人間が「最初の一歩」を踏まなくなってる。

**もえちゃん**: それ、まさに同じ話なんですよ。もう1本、同じ{Zenn|ゼン}から「あ、これ前も言ったな、から始める Claude Code の育て方」という投稿。

**レイナ姐さん**: タイトルからして、もう相手をペットみたいに扱ってるでしょ。

**もえちゃん**: そうなんです。主張は、AIエージェントに繰り返し同じ指示を出してることに気づいたら、それを「ルール文書」に落とせ、というもの。関連する記事が{Zenn|ゼン}にもう1本、「AGENTS.md に書くべきは、リポジトリを読んでも分からないことだけ」。

**レイナ姐さん**: AGENTS.md、エージェントにリポジトリの掟を教える、あの標準ファイルね。

**もえちゃん**: はい、そこに「コードを読めば分かることは書くな。読んでも分からない歴史的経緯とか、暗黙のルールだけ書け」と提案してるんです。エンジニアの仕事の一部が「コードを書く」から「AIに読ませるための文書を書く」にシフトしてる。

**レイナ姐さん**: 正直に言っていい？それって、あたしたち医療現場のプロトコル文書と、まったく同じ発想よ。ベテランがいなくなっても病棟が回るために「暗黙知を書き出す」作業、看護師も何十年も前からやってる。エンジニアがようやくそっち側に来た、って感じ。

**もえちゃん**: 姐さん、その視点めちゃくちゃ効きますね。次いきましょう。{Zenn|ゼン}「あなたのClaude Codeは直列ですか？うちは並列です」、これはエンジニアがAIエージェントを同時に何本も走らせて仕事してる話。

**レイナ姐さん**: 何本も同時に走らせるって、監視できてるの？

**もえちゃん**: そこがポイントで、{Zenn|ゼン}に別の投稿があるんです、「ツール呼び出しの55.5%はサブエージェントが出していた、画面に見えているのは半分以下だった」。人間の目に映ってる作業は、実は半分以下だったっていう分析結果。

**レイナ姐さん**: 見えない部分で走ってる。人間はそこを信頼して、見えるとこだけ判断してる。これ、パイロットが自動操縦をどこまで信じるかって話と、ほとんど同じ構造よ。

**もえちゃん**: 副操縦士どころか、機体そのものが賢くなってる時代なんですよ。じゃあコスト面はどうか。{株式会社OSA（GIGAZINE）|ギガジン}が伝えてた「Spotifyのエンジニアが Claude Code のトークン消費を約90％削減した方法」。9割ですよ、9割。ムダに動かしてたAIの動きを整理しただけで。

**レイナ姐さん**: 削れた9割は、何やってたのよ。

**もえちゃん**: それを別の角度で書いてるのが{Zenn|ゼン}「Claude Code の請求の8割は、居座り続けた出力だった」という記事。エージェントが目的を達成した後も、応答を出し続けて、ずっと課金され続けてた。人間の仕事も同じで、「いつ止めるか」の判断が実はコストの大半を決めてる、と。

**レイナ姐さん**: 止めるって、看護でも一番難しいのよ。処置を「これ以上やらない」って決めるほうが、「もう一つやる」より難易度が高い。エンジニアも同じ壁にぶつかってるのね。

**もえちゃん**: 前編の締めに1本、今週いちばん刺さった記事です。{アイティメディア}「それ、うまくいかないよ ——ベテランの壁だった開発者の態度を一変させた、新人の工夫が参考になる」。

**レイナ姐さん**: タイトルにもう物語があるじゃない。

**もえちゃん**: ある現場でベテランが新しいやり方を「うまくいかない」と却下してた、と。ところが新人がAI相手に何十回も試して、動く形にしてから持ち込んだら、ベテランが「ならやってみるか」と態度を変えた、という記事です。

**レイナ姐さん**: あたしね、「コーディングはもう解決した」っていう業界内の強い言い方、あるでしょ。あれ、あたしはまだ賛成しないのよ。今の記事みたいに、AIが吐いたものを「もう一回動かして見せる」責任は、まるまる人間側に残ってる。

**もえちゃん**: わたしは逆で、「もう解決した」に近い実感があって、姐さんとここで割れます。書く時間はもう主戦場じゃないんですよ。書かれた結果をどう並べて、どう他人に納得させるか、そっちが仕事の中心にきてる。研究室でもコードは半分以上、AIが下書きしてる状態なんです。

**レイナ姐さん**: あんたと意見が割れるの久しぶりね。悪くないわ。

## Part 4: 特集・後編「未来のエンジニアは何をしているか。自分たちは今どう振る舞うか」

**もえちゃん**: じゃあ後編、5年後の景色を描きにいきましょう。

**レイナ姐さん**: 未来から見て、今週の記事が何を予告してたか、を読むわよ。まず{Bloomberg L.P.|ブルームバーグ}「中国のAI業界、モデルからエージェントへ軸足を移す」というレポート記事。中国のAI企業の重心が、基盤モデルの精度競争から、動くエージェントの実装競争に移った、と。

**もえちゃん**: 世界のトップ層が、モデル自慢のフェーズから「業務で回るエージェント」の実装勝負に、一斉に切り替わってるんです。

**レイナ姐さん**: つまり、エンジニアが向き合う相手は「モデル」じゃなくて「動くエージェント群」に確定した、ってことね。

**もえちゃん**: そこに乗ってくるのが、{Zenn|ゼン}「なぜエージェントハーネスで開発パイプラインを作っているのか」という現場ブログ。エンジニア個人が、自分のためのエージェント配線図を作って、日々の仕事をその上で流し始めてる。

**レイナ姐さん**: 「自分専用の職場を、自分で組む」時代ね。

**もえちゃん**: そうなんですよ！さらに{Zenn|ゼン}「Claude Code の memory と skill を分けて設計した、事実と手順の置き場所」という記事。人間がエージェントに何を覚えさせるか、何を毎回やらせるかを、司書みたいに整理してる。

**レイナ姐さん**: ちょっと待って、それ聞いてて思ったんだけど、5年後のエンジニアって、「AIエージェントの人事担当」に近いのよ。誰を雇って、何を覚えさせて、どこで働かせて、いつクビにするか。それを設計してる人。

**もえちゃん**: 姐さん、その言い方すごくいいです。同じ流れで気になるのが{日経BP（日経xTECH）|日経クロステック}の「AIエージェント同士が縄張り争い、矛盾した指示によるリスク判明」という記事。エージェントを複数動かすと、指示の食い違いでシステムが揺れる、と。

**レイナ姐さん**: 病棟で人間の看護師同士が指示のズレで揉めるのと、まったく同じ構図よ。「調整する人」が真ん中にいないと、機械同士でも衝突する。5年後のエンジニアの仕事は、まさにその「調整席」なのよ。

**もえちゃん**: では、いよいよ「じゃあ自分たちは今から何をするか」の話にいきます。ここで敢えて、明るい記事じゃないほうを1本置きます。{IEEE（IEEE Spectrum）|アイ・トリプル・イー・スペクトラム}の「An Engineer's Guide to Surviving a Layoff」——エンジニアが解雇に遭ったときの生存ガイド、という記事です。

**レイナ姐さん**: 朝から重い一本ね。

**もえちゃん**: でも「AIが書ける仕事から順に減っていく」現実は動いてる。この記事の結論は、身も蓋もないんですけど、「日ごろから発信していた人、社外に顔を出していた人、書ける物を持っていた人ほど、次の場所が早く見つかる」。要は、コードを書く時間を減らして、「自分が何をできる人か」を外に置いておいた人が強い、と。

**レイナ姐さん**: あんたと意見が割れた話に戻すわよ。あたしは「コーディングはもう解決した」に懐疑的だけど、「エンジニアが書く人から抜ける」流れは、あたしも認めるの。じゃあ何をするか、って言われたら、あたしは3つに分ける。

**もえちゃん**: 3つ、聞きたいです。

**レイナ姐さん**: 逃げる人。今のポジションで手を動かし続けて、5年後に「自分にしかできない仕事」が残ってると信じる人ね。悪くないけど、椅子取りゲームで椅子が減る前提だから、座り続けてる人だけが勝つの。

**もえちゃん**: シビア。

**レイナ姐さん**: 待つ人。会社が方針を出すまで動かない人。5年後、会社の言うことは変わってるけど、この人の中身は変わってない。市場価値としては、一番危ないわね。

**もえちゃん**: 一番怖いパターンだ。

**レイナ姐さん**: 先に動く人。AGENTS.md 書き始めた人、自分のエージェント配線図を作った人、AIに相談する癖をつけた人。5年後、この人たちは「書く人」じゃなくて、「AIチームのマネージャー」になってる。給料の出所も、たぶん変わってる。

**もえちゃん**: わたしからも1つ。研究室で見てて思うのは、「先に動く人」って、実は派手じゃないんですよ。地味に、AGENTS.md 直したり、自分用のスキルファイル整えたり、「AIに前と同じ間違いをさせない仕組み」を毎日ちょっとずつ入れてる。決してドカンと変わらない、日々のメンテナンスなんです。

**レイナ姐さん**: 分かるわ。派手な人が勝つゲームじゃないのよ、これ。

**もえちゃん**: リスナーのみなさんへ問いかけです。あなたの仕事で、明日誰かに「それ、もう解決した」って言われたら、あなたは何をする人になっていますか？

**レイナ姐さん**: あたしからも1つだけ。「今の仕事が5年後もあると信じたい気持ち」と、「5年後の自分に何を残しておくか」は、別のタスクよ。両方やる。片方じゃ足りない。
